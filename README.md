# Claude 3 Multimodal Cookbook

![Claude 3](https://upload.wikimedia.org/wikipedia/commons/thumb/8/80/Anthropic_Logo.svg/2560px-Anthropic_Logo.svg.png)

## 📌 Project Overview
This Jupyter Notebook provides a quick start guide for using **Claude 3 Haiku** with **LlamaIndex** for text and vision-based tasks. It includes API integration, multimodal processing, and vector storage using **SingleStoreDB**.

## 🚀 Features
- **Text and Image Processing** with Claude 3 Multimodal.
- **Anthropic API Integration** for seamless LLM interactions.
- **Vector Storage Support** using SingleStoreDB.
- **Quick Setup** for AI-based applications.

## 🛠 Installation
To install the required dependencies, run the following command:
```bash
pip install llama-index llama-index-llms-anthropic llama-index-multi-modal-llms-anthropic llama-index-vector-stores-singlestoredb --quiet
```

## 📜 Usage
1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/Claude-3-Multimodal-Cookbook.git
   cd Claude-3-Multimodal-Cookbook
   ```
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Set up your **Anthropic API Key** in the notebook.
4. Run the Jupyter Notebook to explore Claude 3’s multimodal capabilities.

## 🖥 Technologies Used
- **Python**
- **Claude 3 Haiku (Anthropic API)**
- **LlamaIndex**
